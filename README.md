# WHAT YOU WANT — V2 UI Prototype

A responsive static frontend concept with an original dark visual system inspired by:
- Horizon-style dashboard hierarchy and polished typography
- Bento-style modular cards and grid composition
- Smooth transitions, hover states and reduced-motion support

## Included
- Responsive homepage for phone, tablet and desktop
- Find Actress and Find Videos entry points
- Quick filters and guided question flow
- Recently searched tabs for actresses and video topics
- Browser-local search history with clear-history control
- 18+ entry confirmation screen

## Run
Open `index.html` in a modern browser.

## Deploy
Upload these files to a GitHub repository and connect the repository to a static hosting service such as Cloudflare Pages.

## Important limitations
This is a frontend prototype only. It has no real performer database, content catalogue, backend, account system, verified external links or live search provider. Search results are sample placeholders.

Before a public launch, implement jurisdiction-appropriate age assurance, privacy/security controls, moderation/reporting, and a verified data workflow. Only include adult performers and lawful, consensual, properly licensed images and listings. Do not scrape or deep-link to third-party services without permission.
